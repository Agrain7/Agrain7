# ASSET_LICENSES — 에셋·라이브러리 출처와 권리

확인일: 2026-11-18. 법률 자문이 아니며, 상업 출시 전 각 조건을 다시 확인해야 한다.

## 1. ⚠️ 사용자 제공 원화 — 출시 전 반드시 권리 확인
| 에셋 | 출처 | 상태 |
|---|---|---|
| `assets-src/reference/beasts_codex.png` 및 여기서 추출한 영물 일러스트 27장 (`public/assets/mounts/*.png`) | 사용자가 대화에 첨부한 이미지(45633.png). 사용자 지시("이 일러스트들을 그대로 넣어")에 따라 배경만 제거해 사용 | **권리 미확인** |
| `assets-src/reference/gameplay_reference.png` | 사용자 첨부(45634.png). 화면 구성 참고용으로만 사용, 게임에 포함하지 않음 | 참고용 |

확인할 것:
1. 이 이미지를 **누가, 어떤 도구로** 만들었는가 (직접 제작 / 외주 / AI 생성 도구).
2. AI 생성 이미지라면: 해당 도구의 **현재 이용 약관과 사용한 플랜**이 상업적 사용을 허용하는지, 생성물 권리 귀속이 어떻게 되는지 (도구·플랜마다 다름 — 생성 당시 약관 기준으로 확인하고 캡처 보관).
3. 외주·타인 제작이라면: 저작권 양도 또는 상업적 이용 허락 계약서.
4. 특정 기존 작품·캐릭터와 지나치게 유사하지 않은지 (청룡·백호 등 사신(四神) 모티프 자체는 전통 소재지만, 개별 디자인의 유사성은 별도 판단).
→ 권리가 불분명하면 출시 전 같은 콘셉트로 새 원화를 제작해 교체한다 ([ASSET_PLAN.md](ASSET_PLAN.md) — 파일명만 맞추면 코드 수정 최소).

## 2. 이 프로젝트에서 코드로 직접 그린 에셋
배경·지형·장식·라이더·몬스터·효과·UI·아이콘(`src/art/*.ts`)과 절차적 사운드(`src/systems/audio.ts`)는 이 프로젝트를 위해 새로 작성한 코드가 실행 시 그린다. 외부 이미지·음원을 쓰지 않는다. (타 게임의 캐릭터·도안을 복제하지 않음)
