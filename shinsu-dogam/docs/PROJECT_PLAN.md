# PROJECT_PLAN — 신수도감 (神獸圖鑑)

최종 갱신: 2026-11-18

## 1. 목표
웹 브라우저(PC·모바일)에서 플레이하는 2D 횡스크롤 라이딩 어드벤처 RPG를 만들고, 외형 중심 부분 유료화로 지속 가능한 1인 독립 게임 사업을 운영한다.
- 슬로건: **영물을 타고, 동방의 세계를 누비다.**
- 첫 월 매출 목표 200만 원(소비자 결제액 기준, 검증 목표이며 보장이 아님) → [ECONOMY_DESIGN.md](ECONOMY_DESIGN.md)

## 2. 참고 이미지 해석 (중요)
첨부 이미지 2장의 역할은 **내용 기준**으로 판단했다.
| 파일 | 내용 | 역할 |
|---|---|---|
| `45634.png` (`assets-src/reference/gameplay_reference.png`) | '신수연기' 포스터 — 가운데 가로 플레이 장면 | **실제 게임 화면 구성 기준** (라이더+영물 왼쪽 중앙, 오른쪽 탐험 공간, 누각·폭포·벚꽃·달, 상단 HUD, 하단 버튼) |
| `45633.png` (`assets-src/reference/beasts_codex.png`) | '영물 도감' — 9종 × 3단계 | **영물 일러스트 그 자체** |

프롬프트 문구상 "첫 번째 이미지의 가운데 플레이 장면"은 실제로는 두 번째로 첨부된 이미지에 있었다. 또한 개발 도중 사용자가 **"영물 일러스트는 참고하지 말고 이 일러스트들을 그대로 넣어"** 라고 지시하여, 영물은 원화를 직접 잘라 사용한다(원 프롬프트의 '복제·트레이싱 금지'보다 사용자의 직접 지시를 우선). 상업적 사용 권리는 사용자가 확인해야 한다 → [ASSET_LICENSES.md](ASSET_LICENSES.md).

## 3. 기술 스택 (2026-11-18 npm 레지스트리 확인)
| 항목 | 선택 | 이유 |
|---|---|---|
| 엔진 | **Phaser 4.2.1** (2026-07 배포, 4.0.0 정식 2026-04) | 장기 유지보수 대상인 최신 메이저. v3(3.90)는 사실상 마지막 버전 |
| 언어 | TypeScript 7.0.2 | 타입 안정성 |
| 빌드 | Vite 8.3.8 | 빠른 개발 서버, 정적 배포 |
| 물리 | Arcade Physics | 가벼운 AABB, 횡스크롤에 충분 |
| 저장 | LocalStorage (스키마 버전 + 마이그레이션) | 회원가입 없이 즉시 플레이 |
| 배포 | Cloudflare Pages (정적) | 무료 플랜으로 시작 가능 |
| 추후 | Supabase(계정·서버 저장), 토스페이먼츠(결제) | 판매 단계에서 연결 |
| 글꼴 | 고운바탕·고운돋움·Noto Serif KR (@fontsource, OFL) | 자체 호스팅, 필요한 글자 묶음만 로드 |

## 5. 다음 단계 (우선순위)
1. 실기기 테스트 (iPhone Safari, Android Chrome, PC Edge) 및 프레임 측정 → TEST_REPORT 갱신
2. 플레이 테스트로 난이도·경험치 곡선 조정 (Lv.30 각성까지 플레이 시간 측정)
3. 영물 프레임 애니메이션 원화 제작 여부 결정 (FIREFLY_PROMPTS / 외주) — 원화 권리 확인 후
4. 개인정보 처리방침·이용약관·환불 정책 작성, 사업자 등록·통신판매업 신고 → PG 심사
5. Supabase 계정 + 서버 구매 내역 → 토스 테스트 키로 결제 검증 → 실결제
6. 다음 지역(운무협곡: 해태 획득) 제작
