# GAME_DESIGN_DOCUMENT — 신수도감

> 영물을 타고, 동방의 세계를 누비다.

모든 수치는 `src/data/*.ts` 가 원본이며, 이 문서는 2026-11-18 빌드 기준 요약이다.

## 1. 정체성
- 장르: 2D 횡스크롤 라이딩 어드벤처 RPG (자동 달리기 아님, 직접 조작)
- 재미 비중 목표: 탐험·라이딩 70% / 가벼운 전투 20% / 성장·수집 10%
- 대상: 게임에 익숙하지 않은 사람도 바로 즐길 수 있는 직관적 조작, 짧은 세션(5분)

## 2. 세계관과 이야기
오래전 인간과 영물이 공존하던 동방의 세계. 균형을 잇던 기운이 흩어지자 어둠이 번지고 영물들은 힘을 잃거나 잠들었다. 영물과 교감하는 탐험가 **하람**은 영물을 만나 함께 여행하며 잃어버린 힘을 되찾아 준다.

전달 방식(짧게): 인트로 3문장 → 구간 시작 제목 카드 → 영물 획득 연출 → 도감 이야기 → 보스 정화 연출 → 고서 조각(수집 기록).

## 3. 핵심 플레이 사이클
접속 → 지도에서 영물 선택 → 구간 진입 → 달리기·점프·활공·비행으로 탐험 → 몬스터 처치(경험치·금화·영기석) → 레벨업 → 영기석·금화로 진화 → 보스·새 구간 → 새 영물 획득 → 도감 완성.

## 4. 조작
| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | A/D, ←/→ | 왼쪽 ←/→ 버튼 |
| 점프 | Space (W/↑도 가능), 길게 누르면 더 높이 | ↑ |
| 공격 (가까우면 근접, 멀면 영물 고유 원거리 · 누르고 있으면 연속) | J | 파랑 소용돌이 |
| 특수 기술 / 필살기 / 돌진 | K / U / L | 빨강 소용돌이 / 연꽃(게이지) / 바람 |
| 영물 교체 / 메뉴 | Q / Esc | 교체 버튼 / 일시정지 |
| 비행 | 공중에서 점프 한 번 더 → 점프 유지 상승, S 하강 | ↑ 유지, ↓ 버튼 |

이동 보조: 코요테 타임 0.1초, 점프 입력 버퍼 0.13초, 가변 점프(일찍 떼면 낮게), 공격 중 방향 전환 허용.

## 7. 전투
- 기본 공격(J): 영물별 근접 판정 상자, 공격 쿨 0.26~0.36초
- 특수 기술(K): 데이터 기반 9종류 — 근접·투사체·번개·광역·숨결(지속)·돌격 돌진·급강하·보호막·회복
- 돌진(L): 무적 시간 포함 회피, 일부 영물은 공격 판정
- 피해: `공격력 × 기술 배율 × (0.9~1.1) − 몬스터 방어`, 받는 피해는 `몬스터 공격 − 방어×0.5` (보호막 감소 적용)
- 피격 무적 1초(깜빡임), 넉백, 기절 시 마지막 석등에서 체력 회복 후 재시작(손실 없음), 낙사 시 체력 15% 감소

### 몬스터 (월하산맥)
| 몬스터 | AI | 특징 |
|---|---|---|
| 붉은 눈의 산돼지 | 순찰 → '!' 예고 → 돌진 | 기본 |
| 산속 도깨비 짐승 | 깡충 뛰어 덮치기 | 오색 비단실 |
| 어둠의 여우 정령 | 공중 부유, 거리 유지, 어둠 구슬 | 월하 꽃잎 |
| 작은 비행 요괴 | 사인 비행, 급강하 | 하늘 구간 |
| 바위 정령 (정예) | 느린 추적, 내려찍기 충격파, 돌 던지기, 넉백 무시 | 영기석 확정 |
| **흑운 산군** (보스) | 돌진(벽에 부딪히면 기절·피해 1.5배), 도약 내려찍기(양방향 지면 충격파), 어둠의 비(경고 표시 후 낙하), 50% 이하 2페이즈(가속·비행 요괴 소환) | 정화 연출 |
구간 단계(tier)마다 체력 +18%, 공격 +12%, 경험치 +15%.
