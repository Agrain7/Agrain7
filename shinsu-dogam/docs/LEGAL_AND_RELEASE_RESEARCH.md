# LEGAL_AND_RELEASE_RESEARCH — 법률·출시 확인 목록

작성일 2026-11-18.

> **이 문서는 법률 자문이 아니다.** 법률 조사를 맡긴 별도 조사 작업이 문서를 끝내기 전에 중단되어, 이 문서는 **확인해야 할 항목과 공식 확인처를 정리한 목록**이다.
> 표기: **[확인]** = 경제 조사([ECONOMY_DESIGN.md](ECONOMY_DESIGN.md) 8장 출처)에서 공식·준공식 자료로 확인한 내용 / **[알려진 내용 — 원문 재확인 필요]** = 일반적으로 알려져 있으나 이번에 법령·고시 원문으로 확인하지 않은 내용 / **[미확인]**.
> 최종 판단은 변호사·세무사 또는 관계 기관(게임물관리위원회, 관할 구청, 공정거래위원회, 개인정보보호위원회, 국세청)에 확인한다.

공식 확인처
- 법령 원문: 국가법령정보센터 <https://www.law.go.kr> (게임산업진흥에 관한 법률, 전자상거래 등에서의 소비자보호에 관한 법률, 개인정보 보호법)
- 등급분류: 게임물관리위원회 <https://www.grac.or.kr>
- 표준약관·전자상거래: 공정거래위원회 <https://www.ftc.go.kr>
- 개인정보: 개인정보보호위원회 <https://www.pipc.go.kr>
- 결제: 토스페이먼츠 개발자센터 <https://docs.tosspayments.com>, 이용요금 <https://www.tosspayments.com/about/fee>

## 1. 게임물 등급분류
### 1.1 확인할 질문
- 무료 플레이 + 유료 꾸미기 상품을 **개발자 자체 웹사이트**에서 제공하는 브라우저 게임이 등급분류 대상인지, 어떤 경로(게임물관리위원회 직접 신청 등)로 받는지 **[미확인]**
- 자체등급분류사업자 제도는 앱 마켓 같은 유통 플랫폼용으로 알려져 있어, 자체 사이트 배포에는 적용되기 어려울 것으로 보임 **[알려진 내용 — 원문 재확인 필요]**
- 소규모·비영리 게임 면제·감면 제도와 적용 조건 **[미확인]**
- 업데이트(새 지역·영물) 때 변경 신고·재분류가 필요한지 **[미확인]**

### 1.4 수수료
- 게임물관리위원회 **심의수수료 조견표**로 산식과 기초가액을 확인했다 **[부분 확인]** — <https://www.grac.or.kr/Institution/EtcForm01.aspx>
- 경제 조사에서는 산식 기준 추정 범위 **약 1.5만~108만 원**, 계획용 예산 **54만 원**(PC온라인·네트워크·2군·개인 50% 감면 가정)을 잡았다. 세부 계산 근거는 문서로 남지 않았으므로 **조견표 원문으로 다시 계산**할 것. 현행 적용 금액·부가세 포함 여부는 **[미확인]**.

## 2. 게임 관련 사업자 의무
- 유료 아이템을 판매하는 개인 개발자에게 **게임제작업·게임배급업 등록**(또는 신고) 의무가 있는지, 관할 구청과 비용 **[미확인 — 관할 구청 확인]**
- 게임 결과물의 환전·환전 알선·재매입을 업으로 하는 행위 금지 (게임산업법 제32조 제1항 제7호로 경제 조사에 기재) **[알려진 내용 — 원문 재확인 필요]** → 이 게임은 사용자 간 거래·현금화 기능이 없다

## 3. 사업자등록·통신판매업 신고
- 개인사업자 등록, 일반/간이 과세 유형 선택 (간이과세 기준: 직전연도 공급대가 1억 400만 원 미만, 연 4,800만 원 미만이면 부가세 납부 면제) **[확인 — 국세청 안내, ECONOMY_DESIGN 4.5]**
- 간이과세자는 통신판매업 신고가 면제되고, 토스페이먼츠 심사 안내에도 간이과세자는 신고번호 없이 진행 가능하다고 되어 있음 **[확인 — 토스페이먼츠 블로그]**
- 통신판매업 신고 절차·비용, 사이트 하단 사업자 정보 표시 항목 **[미확인 — 관할 구청·공정위 확인]**

## 4. 청약철회·환불
- 전자상거래법상 청약철회 기간(일반적으로 7일)과, 디지털콘텐츠는 '제공이 개시된 경우' 철회를 제한할 수 있되 **사전 고지와 시용(미리보기) 등 조치**가 필요하다는 점 **[알려진 내용 — 원문 재확인 필요]**
- 현재 설계: 구매 전 미리보기(스킨은 원화 색 미리보기), 미사용 상품 7일 내 환불, 패키지는 구성품별 정가 표시 → 정책 문구는 원문 확인 후 확정
- 토스페이먼츠 결제 취소 API로 전액·부분 취소 가능, 카드 결제 취소 시 수수료 환급 **[확인]**
- 2024년 2월 게임 표준약관 개정(서비스 종료 후 30일 이상 미사용 유료 아이템 환불 창구) **[확인 — 언론 보도, 약관 원문 미확인]**
- 미성년자 결제: 법정대리인 동의 없는 계약 취소권 관련 고지·처리 절차 **[미확인]**

## 5. 확률형 아이템
- 확률형 아이템 정보 공개 의무(2024년 3월 시행으로 알려짐) **[알려진 내용 — 원문 재확인 필요]**
- 현재 게임: **유료 확률형 상품 없음** (단위 테스트로 상품 분류 검사). 보물 상자의 무작위 보상은 무료로만 얻는다. 유료 상품이 무작위 보상의 양·확률에 영향을 주면 '간접 유상' 대상이 될 수 있으므로 피한다 (ECONOMY_DESIGN 6장)
- 탐험 패스·이벤트 도입 시 다시 검토

## 6. 개인정보
- 현재: 회원가입 없음, 진행 상황·분석 이벤트를 **이 브라우저(LocalStorage)에만** 저장, 서버 전송 없음, 쿠키·광고 식별자 없음
- 그래도 공개 시 개인정보 처리방침을 게시하는 것이 안전 — 필수 항목과 '수집하지 않음' 고지 방법 **[미확인 — 개인정보보호위원회 작성 지침 확인]**
- 계정(Supabase)·결제 도입 시: 수집 항목(이메일 등), 목적, 보유 기간, 처리 위탁(Supabase, Cloudflare, 토스페이먼츠), 국외 이전(해외 클라우드) 고지 필요 여부 **[미확인]**
- 분석 수집 서버를 연결하면 식별자 수집 여부에 따라 처리방침 개정

## 7. 청소년
- 셧다운제는 2022년에 폐지된 것으로 알려짐 **[알려진 내용 — 원문 재확인 필요]**
- 청소년 결제 한도·보호 조치 의무 여부 **[미확인]**

## 8. 토스페이먼츠 가맹
- 수수료: 신용·체크카드 3.4%(부가세 별도), 가입비 220,000원, 연관리비 110,000원(표준 표기) **[확인]** — ECONOMY_DESIGN 4.1, 5장
- 심사 안내상 게임 업종 **1일 최대 결제 5만 원 미만** 기준 **[확인 — 블로그, 적용 단위 미확인]** → 게임에 계정당 하루 누적 5만 원 미만 제한 구현(클라이언트), 서버 검사 추가 예정
- 필요 서류·사이트 요건(이용약관·환불정책·사업자 정보 표시 등) **[미확인 — 가맹 신청 시 안내 확인]**
- 결제 승인 흐름: 결제창 → successUrl 로 paymentKey·orderId·amount 전달 → 서버가 저장된 주문 금액과 비교 → 시크릿 키(Basic 인증)로 승인 API 호출 → 소유권 기록. 코드 골격은 `functions/api/` 에 작성했으나 **공식 문서 최신판으로 엔드포인트·요청 형식을 다시 확인하고 테스트 키로 검증해야 함** **[미확인]**
