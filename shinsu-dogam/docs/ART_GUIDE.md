# ART_GUIDE — 신수도감 아트 디렉션

## 1. 원칙
- **완전한 2D**: 3D 모델·렌더·카메라, 아이소메트릭·탑뷰·쿼터뷰, 도트·픽셀아트, 서양 판타지, CSS 도형 캐릭터 사용 안 함.
- 한국 전통 채색화·민화·산수화·단청·구름 문양에서 영감을 받은 **2D 핸드페인팅** 스타일.
- 배경은 회화적으로, 플레이어·지형·몬스터·수집품은 선명한 외곽선과 대비로 쉽게 구분되게.

## 2. 참고 이미지 분석
### 게임 플레이 화면 기준 (`assets-src/reference/gameplay_reference.png`, 가운데 가로 장면)
- 측면 시점, 라이더+영물은 화면 왼쪽 중앙, 오른쪽으로 탐험 공간이 열림
- 원경: 보랏빛 산맥과 커다란 금빛 달, 구름 / 중경: 절벽 위 궁궐(기와·붉은 기둥), 폭포 / 근경: 벚꽃·매화나무, 석등, 누각 / 지면: 풀 덮인 돌 지형, 돌다리
- UI: 좌상단 원형 초상 + Lv + 빨강 체력·파랑 경험치 바, 우상단 지역명 캡슐 + 일시정지, 하단 좌 ←→, 하단 우 스킬·점프 원형 버튼(금테)
→ 위 구성을 그대로 따르되 모든 요소는 레이어로 분리해 실제 패럴랙스로 움직인다 (포스터를 배경으로 쓰지 않음).

### 영물 일러스트 (`assets-src/reference/beasts_codex.png`)
- 사용자 지시에 따라 **원화를 그대로 잘라 사용**한다. 9종 × 3단계 = 27장.
- 특징: 굵고 선명한 갈색·남색 외곽선, 풍부한 채색, 금색 구름 장식, 붉은 매듭·술, 각성체일수록 장식·갈기·구름이 많아짐.

## 3. 영물 일러스트 처리 규칙 (`tools/extract_beasts.py`)
1. 원본 좌표 상자로 자르기 (단계 사이 화살표·패널 테두리는 지움)
2. 가장자리와 이어진 종이색(베이지)과 발밑 그림자 제거 → 그림 내부의 흰 털은 보존
3. 갈기·구름 사이에 갇힌 종이 영역 제거 (평균 색 거리 < 9, 따뜻한 색조, 결이 고른 영역만)
4. 경계 2px 부드러운 알파 + 종이색 언프리멀티플라이(밝은 테두리 제거)
5. **좌우 반전** — 원화는 모두 왼쪽을 보므로 게임 기준(오른쪽)으로 통일
6. 그림 픽셀 자체는 수정하지 않는다 (색 보정·덧칠 없음)

## 4. 영물 애니메이션 (`src/art/mountFrames.ts`)
원화가 한 장씩이므로 **원화를 다시 그리지 않고 픽셀 변형**으로 움직임을 만든다.
| 종류 | 대상 | 방식 |
|---|---|---|
| quad | 늑대·백호·기린·해태·청룡 유체 | 다리 영역(legLine 아래)을 앞/뒤 반대 위상으로 흔들어 달리기 |
| bird | 매·주작·봉황 | 날개 뿌리(wingRoot) 위 영역을 수직 압축·확장 → 날갯짓 |
| serpent | 청룡 성장체·각성체 | 몸 전체에 꼬리 쪽이 크게 움직이는 물결 |
| shell | 현무 | 느린 걸음 |
- 프레임: idle 4, run 6, fly 6 (+ 점프/낙하/공격/피격은 기울기·늘이고 누르기·돌출·붉은 깜빡임으로 표현)
- 원점: 그림 하단 중앙 = 지면 접점, 라이더 좌석은 `src/data/mountArt.ts` 의 seat 비율
- ⚠️ 한계: 정식 프레임별 원화(달리기 8프레임 등)보다 동작 표현이 단순하다. 품질을 더 올리려면 같은 디자인으로 프레임별 원화를 제작해야 한다 → [FIREFLY_PROMPTS.md](FIREFLY_PROMPTS.md), [ASSET_PLAN.md](ASSET_PLAN.md)
- 스킨: 원화를 HSL 색조 변환(무채색 부분은 덜 바꿈)해 색 변형. 디자인 자체는 그대로.

## 5. 코드 페인팅 요소 (`src/art/*.ts`)
원화가 없는 요소는 Canvas 2D로 그린다: 스플라인 외곽선, 그라데이션 명암, 털·비늘 결, 금 소용돌이, 매듭·술.
- 라이더 하람: 2~3등신, 검은 쪽머리 + 비녀 + 붉은 댕기, 흰 저고리 + 붉은 고름 + 붉은 치마. 의상 6종(기본·색동·무사·선녀·궁중·겨울)
- 몬스터: 먹색 몸 + 붉은 주술 문양(어둠에 물듦을 표현), 붉게 빛나는 눈
- 배경: 산수화 붓질의 원경, 이끼 낀 절벽, 기와 궁궐, 폭포(스크롤), 벚꽃·매화나무, 정자, 석등, 홍살문(골), 엽전(금화)
- UI: 한지 패널(회문 모서리), 옻칠 버튼(금테), 원형 터치 버튼

## 7. 화면 가독성 규칙
- 플레이어 깊이 10, 몬스터 8, 지형 -10 ~ -8, 장식 -13 ~ -11 (플레이어가 항상 앞)
- 몬스터 위 체력바 상시 표시(정예는 금색), 공격 예고는 '!'
- 보스 낙하 공격은 지면에 붉은 경고 원
- 글자: 제목 고운바탕, 본문 고운돋움, 한자 Noto Serif KR
