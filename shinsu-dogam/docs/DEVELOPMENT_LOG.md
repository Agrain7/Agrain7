### PHASE 1 — 플레이 가능한 코어
- 구현: 2D 횡스크롤 카메라(진행 방향 앞쪽을 넓게, 부드러운 추적), 지형 충돌(Arcade static), 한 방향 발판, 늑대+라이더, 가속·감속 이동, 점프(코요테 타임·입력 버퍼·가변 높이), 착지, 방향 전환, 7겹 패럴랙스, 키보드 + 멀티터치 버튼
- 수정한 오류: 헤드리스 브라우저(창 포커스 없음)에서 Phaser가 프레임 시간을 1/60초로 묶어 느리게 움직이던 현상 → 게임 코드 문제가 아니라 테스트 환경 문제로 확인, 테스트 하네스에서 포커스 상태 유지

### PHASE 2 — 2D 그래픽
- 처음에는 영물을 Canvas 2D로 직접 그리는 방식(늑대·청룡 페인터)으로 시작했으나, **사용자 지시("영물 일러스트는 참고하지 말고 이 일러스트들을 그대로 넣어")에 따라 폐기**하고 원화 추출 방식으로 전환
- `tools/extract_beasts.py`: 27장 추출. 시행착오:
  - 단순 가장자리 채우기 → 각성체에서 패널 테두리가 경계를 막아 종이 배경이 남음
  - AI 배경 분리 모델(rembg isnet-anime) 시도 → 작은 유체 그림을 지워 버려 **채택하지 않음**
  - 최종: 종이색 가장자리 채우기 + '갇힌 종이 영역' 색·결 판별 + 패널 테두리 좌표 제외 + 부드러운 알파·언프리멀티플라이
- 영물 애니메이션: 원화 픽셀 변형(다리 흔들기·날갯짓·몸 물결) — `src/art/mountFrames.ts`
- 배경·지형·장식·라이더·몬스터·UI·효과: 코드 페인팅 (`src/art/`)
- 미완료: 프레임별 원화 애니메이션, 라이더·몬스터·배경의 원화 수준 일러스트 (ASSET_PLAN 2절)
